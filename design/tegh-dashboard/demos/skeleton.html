How to use it

1. Give a panel three layers

<div class="sk-region" id="r-ar">
  <div class="sk-layer" aria-hidden="true">
    <span class="sk sk-number" style="width:58%"></span>
    <span class="sk sk-line" style="width:86%"></span>
  </div>
  <div class="sk-content">… real content …</div>
  <div class="sk-error" role="alert">… retry …</div>
</div>

2. Load it

TeghSkeleton.load('#r-ar',
  () => api('dashboard/summary'),
  {
    render: (data, region) => { /* fill .sk-content */ },
    renderError: (err, region, retry) => {
      region.querySelector('[data-retry]').onclick = retry;
    }
  });

Building blocks

  • sk-line, sk-title, sk-number: text and figures. Set a width so lines look like real text.
  • sk-pill, sk-circle, sk-square, sk-box: chips, avatars, icons, panels.
  • sk-bars with sk-group and --h: a bar chart. sk-wave: a line chart.
  • sk-in on content pieces makes them rise in one after another.

Built in

  • No flash: the placeholder only appears if the data takes longer than 150 ms, and then stays at least 450 ms.
  • No jumping: placeholder and content share one space, so the page never shifts.
  • One shimmer sweeps across the whole screen, so all placeholders move together.
  • Screen readers hear that a panel is busy, not the placeholders. Motion is switched off for people who turn it off on their device.
