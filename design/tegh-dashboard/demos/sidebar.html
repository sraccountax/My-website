Cedar & Co. (Sample)

Dashboard

Try it

Click the chevron at the top of the sidebar to switch between the full menu and the icon rail. In the rail, hover over an icon for its name, and click Receivables or Reports to open their menus beside the rail. Make the window narrower than 900 pixels (or open this on a phone) to get the slide-in drawer.

What the sidebar reported

    Keyboard

    • [ Collapse or expand the sidebar
    • Ctrl K Search
    • ↑ ↓ Move through the menu
    • → ← Open or close a group
    • Home End First or last item
    • Esc Close the drawer or a menu

    How to add it to a page

    1. The page frame

    <link rel="stylesheet" href="../assets/tegh-sidebar.css">

<div class="ts-shell">
  <aside id="sidebar"></aside>
  <div class="ts-main" id="main">
    <button id="menu" aria-label="Open menu">☰</button>
    … your page …
  </div>
</div>

<script src="../assets/tegh-sidebar.js"></script>

    2. Describe the menu

    const sidebar = TeghSidebar.mount('#sidebar', {
  main: '#main',             // locked while the drawer is open
  active: 'dashboard',
  company: { name: 'Cedar & Co.' },
  user: { name: 'Priya Sharma', role: 'Owner' },
  sections: [{
    label: 'Workspace',
    items: [
      { id: 'dashboard', label: 'Dashboard', icon: 'dashboard' },
      { id: 'banking', label: 'Banking', icon: 'banking', badge: 14 },
      { id: 'receivables', label: 'Receivables', icon: 'receivables',
        children: [
          { id: 'invoices', label: 'Invoices' },
          { id: 'aged-ar', label: 'Aged receivables' }
        ] }
    ]
  }],
  onNavigate: (id) => openPage(id),
  onCollapse: (collapsed) => savePreference(collapsed)
});

document.getElementById('menu')
  .addEventListener('click', e => sidebar.openDrawer(e.currentTarget));

    3. Control it from your code

    sidebar.setActive('aged-ar');   // highlight a page
sidebar.setBadge('banking', 17);  // update a count
sidebar.collapse(true);           // icon rail
sidebar.toggle();                 // rail on desktop, drawer on phones
sidebar.openDrawer();  sidebar.closeDrawer();
sidebar.destroy();

    Options

    1. breakpoint: below this width (default 900 pixels) the sidebar becomes a drawer.
    2. collapsed: start as the rail. Without it, the last choice saved in the browser is used.
    3. footerCard: { eyebrow, title, progress } for the gold panel at the bottom.
    4. onSearch, onCompany, onUser: what the search, company and account buttons do.
    5. onNavigate returning false leaves the highlight where it is, for example while a form has unsaved changes.
    6. Icons: dashboard, banking, receivables, payables, ledger, payroll, reports, tax, assist, documents, settings, help, or any 24×24 SVG path.
    7. Sizes and colours are CSS variables on .ts, such as --ts-w, --ts-w-rail, --ts-teal and --ts-gold.
