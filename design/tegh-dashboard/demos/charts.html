How to use it

1. Add the two files

<link rel="stylesheet" href="../assets/tegh-charts.css">
<script src="../assets/tegh-charts.js"></script>

2. Give each chart an empty box

<div id="cashflow"></div>

3. Draw it with your numbers

const chart = TeghCharts.bar('#cashflow', {
  labels: ['Aug', 'Sep', 'Oct'],
  series: [
    { name: 'Money in',  values: [34600, 39200, 42100] },
    { name: 'Money out', values: [30100, 32300, 33000] }
  ]
});

// New figures animate from the old ones:
chart.update({ labels, series });

The other charts

TeghCharts.line('#forecast', {
  labels, series: [{ name: 'Bank balance', values }],
  forecastFrom: 7,   // dashed after this point
  markMin: true      // label the lowest point
});

TeghCharts.waterfall('#profit', { steps: [
  { label: 'Revenue', value: 412600, total: true },
  { label: 'Cost of sales', value: -96300 },
  { label: 'Gross profit', value: 316300, total: true }
]});

TeghCharts.hbar('#expenses', { items: [
  { label: 'Rent', value: 34560 },
  { label: 'Everything else', value: 14410, muted: true }
]});

TeghCharts.kpi('#cash', { label: 'Cash at bank',
  value: 48210, previous: 41230, spark: [...] });

Options

  • format and tipFormat: how values print on the axis and in the tooltip. Built in: TeghCharts.format.money, moneyShort, percent.
  • height in pixels; the width always follows the box.
  • animate: false to switch animation off; duration and stagger in milliseconds.
  • table: false hides the Table button.
  • KPI: goodWhen: 'down' for figures where lower is better, such as expenses.
  • Every chart returns update(), replay() and destroy().

Built in

  • Redraws when the box changes size, so it works on phones.
  • Follows light and dark mode, using colours tested for colour blindness.
  • No animation for people who turn motion off on their device.
  • Keyboard: click or Tab into a chart, then use the arrow keys, Home, End and Esc.
